# Phase 6 Windows and GPU Progress — 1.5.0 RC

**Current status (2026-10-26):** Windows is unsupported and excluded from the proposed paid offer; CUDA and Vulkan are experimental. Exact-head hosted Windows CI, ten consecutive six-theme certifications, Windows 11 installer acceptance, and matching-hardware GPU production rendering remain unverified. The GUI wizard, backend/device pickers, tooltips, menu action, CLI help, documentation, and both EULA copies now label the GPU paths experimental. The canonical Linux/offscreen full test suite passed; that run is not Windows or GPU qualification.
